
# **Задача 1 — Класс `Complex`**

Реализовать класс комплексных чисел:

* конструктор по умолчанию;
* конструктор с параметрами;
* копирующий конструктор;
* методы `getReal()`, `getImag()`, `setReal()`, `setImag()` (корректная const-semantics);
* операторы `+`, `-`, `*`, `/`;
* операторы `==`, `!=`;
* операторы ввода/вывода `<<` и `>>`;
* метод `modulus() const`.

# **Задача 3 — Класс `CSVReader`**

Реализовать CSV-парсер:

* конструктор по умолчанию;
* перегрузка оператора ввода `>>` (чтение CSV из потока);
* перегрузка оператора вывода `<<` (печать CSV);
* метод `countNonEmptyCellsPerColumn() const`, возвращающий количество непустых ячеек в каждом столбце;
* демонстрация работы в `main`.
